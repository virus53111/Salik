# CenaRadar — cenaradar.online

**Статус:** действующий проект. **Не удалять.**

- **Сайт:** https://cenaradar.online/
- **Основной код:** этот репозиторий, ветка `main`. Старое имя репозитория — `Salik`.
- **Назначение:** строительные и ремонтные цены в Латвии, калькуляторы и сметы.
- **Хостинг по публичному DNS на 14.11.2026:** Render (`www.cenaradar.online` → `cenaradar.onrender.com`; A-запись корня `216.24.57.1`).
- **Панель хостинга:** https://dashboard.render.com/
- **DNS домена:** `dns1.registrar-servers.com` и `dns2.registrar-servers.com`.

## Важно

Файл `DEPLOY-CENARADAR.md` описывает **старый вариант публикации через GitHub Pages**. Сейчас DNS указывает на Render. Не заменяйте DNS на настройки из старого файла без проверки.

Связь действующего Render-сервиса с этим репозиторием и настройки автоматического деплоя ещё необходимо проверить в **Render → Service → Settings → Build & Deploy**.

В корне находятся действующие файлы сайта (`index.html`, `styles*.css`, `app*.js`, статьи, калькуляторы). Не удаляйте их без проверки.

**Предлагаемое название репозитория:** `cenaradar-website` — только после проверки подключенного репозитория в Render.
